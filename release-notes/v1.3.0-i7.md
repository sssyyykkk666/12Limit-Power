为 MacBook10,1 / Intel Core i7-7Y75 / Intel HD Graphics 615 编译的 1.3.0 版本，面向 macOS 13 Intel。

- 在原 m3 实现上适配 i7，应用、安装器和后端均区分 CPU。
- 修复写死用户名 / UID / 源码路径，读取本机基线，保留原始恢复配置。
- 提供 PL1 / PL2、睿频开关、独立可编辑预设、自定义、回读验证和失败回退。
- 增加临时目录安装器、后端未就绪提示和残留刷新请求处理。
- README 收录本次恢复模式、驱动加载与初始化的完整实际操作教程。

下载并完整解压 `12Limit-Power-1.3.0-i7.zip`，按 README 操作，再运行根目录 `Install.command`。不要只复制 `.app`。应用使用本地签名，未经过 Apple 公证；驱动加载需要教程中的系统设置。

验证：macOS 13.7.8 i7 实机已成功加载驱动、保存基线并恢复 / 回读原始 49 / 49W 和睿频状态；1.3.0 两种 CPU 模拟测试、窗口自测及签名检查通过。未宣称新的节能档位已完成压力或续航测试。读到的单核 / 双核睿频上限为 3.6 / 3.4GHz，当前不提供倍率写入或独立 GPU 锁频。
