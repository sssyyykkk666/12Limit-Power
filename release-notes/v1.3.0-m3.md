为 MacBook10,1 / Intel Core m3-7Y32 / Intel HD Graphics 615 编译的 1.3.0 版本，面向 macOS 13 Intel。

- 保留原 m3 版的封装功耗、睿频、独立预设、自定义与失败回退功能。
- 修复写死用户名 / UID / 源码路径，读取每台设备自己的安装前基线。
- 增加 CPU 校验、后端未就绪提示、临时目录安装器及残留刷新请求处理。
- README 提供恢复模式 `csrutil enable --without kext`、驱动批准 / 重启、安装、升级、排错和卸载教程。

下载并完整解压 `12Limit-Power-1.3.0-m3.zip`，按 README 操作，再运行根目录 `Install.command`。不要只复制 `.app`。应用使用本地签名，未经过 Apple 公证；驱动加载需要教程中的系统设置。

验证：m3 / i7 模拟控制器测试、参数策略测试、两种窗口自测及签名检查通过。新 m3 构建尚未在 m3 实机重新验证；原 m3 倍率写入测试不通过，本版不提供固定 GHz 或独立 GPU MHz 控制。首次安装保留原始设置，选档后才限功耗。原始 49W 不代表可持续散热能力。
